Where these numbers come from

        
This panel reads local files and asks your model endpoint. Nothing is uploaded and no credential leaves this machine.

        

          
Token usage

          
Read read-only from the project's local Hermes database (state.db, table
            session_model_usage) plus messages and sessions. Counts are what
            Hermes itself recorded, per model and per day.

          
Insights

          
Same local database (per-day and per-hour message counts, tool usage, session context and
            compression state) and the project's logs/errors.log digest.

          
Model list

          
Fetched from the endpoint configured in this project (model.base_url, for example
            https://api.example.com) via /v1/models, cached for 12 hours, with an
            optional local catalog file as fallback when the endpoint cannot be reached. The endpoint is
            whatever that machine configured, never a built-in one.

          
Cost estimate

          
Token counts multiplied by third-party price tables (the local models.dev cache and any local catalog file). Treat it as an estimate, not an invoice.
